# TRINITE 홈페이지 — 설치·운영 가이드

라이브 사이트에서 **로그인 → 프로젝트·이미지 업로드 → 자동 반영**되는 구조입니다.
아임웹 없이, 본인 도메인으로 운영합니다.

```
[내가 /admin 에서 프로젝트 등록]
        ↓ (자동 저장)
[GitHub 저장소에 커밋]
        ↓ (자동 배포)
[Netlify → 내 도메인에 반영]
```

- **호스팅**: Netlify (무료)
- **저장소**: GitHub (무료)
- **CMS(관리자)**: Sveltia CMS — 별도 서버 없이 GitHub 토큰으로 로그인
- **비용**: 도메인 값을 제외하면 0원

---

## 폴더 구조
```
index.html            # 홈페이지
netlify.toml          # 배포 설정
data/
  └─ projects.json    # 프로젝트 데이터 (CMS가 자동 관리)
images/
  └─ uploads/         # 업로드한 이미지가 저장되는 곳
admin/
  ├─ index.html       # 관리자 페이지 (Sveltia CMS)
  └─ config.yml       # CMS 설정  ★ repo 값 수정 필요
```

---

## 준비물
1. **GitHub 계정** — https://github.com (무료 가입)
2. **Netlify 계정** — https://netlify.com (GitHub로 가입하면 편함)
3. **본인 도메인** — 이미 보유

---

## STEP 1. GitHub 저장소 만들고 파일 올리기

1. GitHub 로그인 → 우측 상단 **＋ → New repository**
2. 저장소 이름 입력 → **`trinite`** (⚠️ 저장소 이름에는 한글을 쓸 수 없습니다. 영문 `trinite` 로 하세요. 브랜드 표기와는 무관한 내부 이름입니다.) → **Private** 또는 Public 선택 → **Create repository**
3. 만들어진 저장소 화면에서 **uploading an existing file** 클릭
4. 이 폴더 안의 **모든 파일과 폴더**(index.html, admin/, data/, images/, netlify.toml)를 드래그해서 업로드 → **Commit changes**
   - ⚠️ 폴더 구조가 그대로 유지되도록, 압축을 푼 **파일·폴더 상태 그대로** 올리세요.
5. **★ 중요:** 저장소의 `admin/config.yml` 파일을 열어 (연필 아이콘 ✎) 아래 줄을 본인 아이디로 수정 후 저장:
   ```yaml
   repo: your-github-id/trinite   →   repo: 본인깃허브아이디/trinite
   ```

---

## STEP 2. Netlify에 연결하고 배포

1. https://netlify.com → **Sign up with GitHub** 로 가입/로그인
2. **Add new site → Import an existing project → Deploy with GitHub**
3. 방금 만든 저장소(`trinite-site`) 선택
4. 배포 설정은 그대로 두면 됩니다:
   - Build command: **비움**
   - Publish directory: **`.`** (루트)
5. **Deploy** 클릭 → 잠시 후 `https://무작위이름.netlify.app` 주소가 생성됩니다. 접속해서 사이트가 뜨는지 확인하세요.

> 앞으로 GitHub에 변경이 생길 때마다(=CMS에서 저장할 때마다) Netlify가 자동으로 다시 배포합니다.

---

## STEP 3. 내 도메인 연결 (아임웹에서 구매한 도메인)

도메인을 아임웹에서 구매하셨으므로, **네임서버 변경이 아니라 아임웹 DNS 관리에서 레코드를 직접 추가**하는 방식으로 연결합니다.

### 3-1. Netlify 쪽 — 도메인 등록 & 값 확인
1. Netlify 사이트 화면 → **Domain management → Add a domain** → 본인 도메인 입력(예: `trinitekr.com`) → **Add**
2. Netlify가 "외부 DNS를 설정하라"고 안내합니다. **Pending DNS verification** 을 눌러 아래 두 값을 확인해 두세요:
   - **www** → CNAME 대상: `내사이트이름.netlify.app` (예: `brave-curie-12345.netlify.app`)
   - **루트(@)** → A 레코드 IP: `75.2.60.5`

### 3-2. 아임웹 쪽 — DNS 레코드 추가
1. 아임웹 **관리자 → 도메인** 메뉴로 이동
2. 해당 도메인이 아임웹 사이트에 **연결되어 있으면 먼저 연결 해제**합니다. (한 도메인은 한 곳에만 연결됩니다.)
3. 도메인의 **DNS 설정(레코드 관리)** 에서 아래 두 개를 추가:

   | 종류 | 호스트 | 값 |
   |------|--------|-----|
   | A 레코드 | `@` (또는 비움) | `75.2.60.5` |
   | CNAME(별칭) | `www` | `내사이트이름.netlify.app` |

4. 저장합니다. (아임웹에서 A레코드·CNAME 추가 방법은 아임웹 고객센터 "도메인 A레코드 설정" / "도메인 별칭(CNAME) 설정" 안내 참고)

### 3-3. 마무리
- DNS 반영에는 보통 수십 분, 최대 24시간까지 걸릴 수 있습니다.
- 반영되면 Netlify가 **HTTPS 보안 인증서를 자동 발급**합니다. (Netlify 화면에 초록색 표시)
- 완료 후 `https://내도메인` 과 `https://내도메인/admin` 이 모두 열립니다.

> ⚠️ 만약 아임웹 도메인 관리에서 A레코드/CNAME 편집 항목이 보이지 않거나 막혀 있다면, 두 가지 대안이 있습니다.
> (1) 아임웹 고객센터에 "타사(Netlify) 호스팅 연결을 위해 A레코드·CNAME을 추가하고 싶다"고 문의, 또는
> (2) 도메인을 **Cloudflare(무료)** 나 가비아 등으로 **기관 이전** 후 DNS를 자유롭게 관리 — 이전에는 인증코드와 며칠의 시간이 필요합니다.
> 막히면 알려주세요. 그 상황에 맞춰 안내하겠습니다.

## STEP 4. 관리자 로그인용 GitHub 토큰 발급 (1회)

Sveltia CMS는 별도 서버 없이 **GitHub 개인 토큰**으로 로그인합니다.

1. GitHub → 우측 상단 프로필 → **Settings**
2. 맨 아래 **Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
3. 설정:
   - **Token name:** 예) `trinite-cms`
   - **Expiration:** 원하는 기간 (예: 1년)
   - **Repository access:** *Only select repositories* → `trinite-site` 선택
   - **Permissions → Repository permissions → Contents:** **Read and write** 로 설정
4. **Generate token** → 나오는 토큰 문자열을 복사해 안전한 곳에 보관 (이 화면을 벗어나면 다시 볼 수 없습니다)

---

## STEP 5. 프로젝트 올리기 (평소 사용법)

1. 브라우저에서 **`https://내도메인/admin`** 접속 (배포 전에는 `무작위이름.netlify.app/admin`)
2. **Sign in with Token** 클릭 → STEP 4에서 만든 토큰 붙여넣기
3. **프로젝트 → 프로젝트 목록**에서
   - **＋ 추가** 로 새 프로젝트 생성
   - 제목·카테고리 선택, **대표 이미지 업로드**(드래그), 필요 시 클라이언트·설명·링크 입력
   - 항목을 끌어서 **순서 변경**도 가능
4. **Save / Publish** 클릭 → GitHub에 자동 저장 → Netlify가 1~2분 내 자동 배포 → 홈페이지에 반영 ✅

---

## STEP 6. 문의 받기 — 문의함 설정 (1회)

홈페이지의 문의 폼은 **Netlify Forms**로 실제 수신되며, 사이트 안의 **비밀번호 보호 문의함 페이지**에서 목록을 확인합니다.
주소: **`https://내도메인/admin/inquiries.html`**

문의 데이터를 안전하게 불러오려면 아래 설정이 한 번 필요합니다.

### 6-1. 폼 인식 (자동)
- 배포하면 Netlify가 홈페이지의 문의 폼을 자동으로 인식합니다.
- 확인: Netlify 사이트 → **Forms** 메뉴에 `contact` 폼이 보이면 정상입니다.
  (폼이 안 보이면, 사이트에서 문의를 **테스트로 1건 전송**한 뒤 다시 확인하세요.)

### 6-2. Netlify 개인 액세스 토큰 발급
1. Netlify 우측 상단 아바타 → **User settings → Applications → Personal access tokens → New access token**
2. 이름 예) `trinite-inquiries` → 발급 → **토큰 복사**(한 번만 표시됨)

### 6-3. 사이트 ID 확인
- Netlify 사이트 → **Site configuration → General → Site information → Site ID** 값 복사

### 6-4. 환경변수 3개 등록
Netlify 사이트 → **Site configuration → Environment variables → Add a variable** 에서 아래 3개를 추가:

| 이름 | 값 |
|------|-----|
| `NETLIFY_API_TOKEN` | 6-2에서 복사한 토큰 |
| `NETLIFY_SITE_ID` | 6-3에서 복사한 Site ID |
| `INQUIRY_PASSCODE` | 문의함 페이지에서 쓸 **비밀번호**(직접 정하기) |

> 저장 후 **재배포**가 필요할 수 있습니다. Netlify → Deploys → **Trigger deploy → Deploy site** 를 한 번 눌러주세요.

### 6-5. 사용
- `https://내도메인/admin/inquiries.html` 접속 → `INQUIRY_PASSCODE` 비밀번호 입력 → 받은 문의 목록 확인
- 새 문의는 이메일로도 알림받고 싶다면: Netlify → **Forms → contact → Settings & notifications** 에서 **이메일 알림**을 추가하세요.

> 🔐 이 방식은 Netlify 토큰이 서버(환경변수)에만 있고 화면에는 절대 노출되지 않아, 비밀번호를 아는 사람만 문의를 볼 수 있습니다.

## 자주 묻는 것 / 문제 해결

**Q. 내 컴퓨터에서 index.html을 더블클릭하면 프로젝트가 샘플 6개만 보여요.**
정상입니다. 실제 데이터(`data/projects.json`)는 웹서버에서만 불러와지므로, 로컬 파일로 열면 기본 샘플이 표시됩니다. 실제 확인은 `netlify.app` 주소나 내 도메인에서 하세요.

**Q. 카테고리를 새로 추가하고 싶어요.**
`admin/config.yml` 의 `options: ["브랜딩", "캠페인", ...]` 에 원하는 이름을 한 줄 추가하면 됩니다. 홈페이지 필터 버튼은 등록된 프로젝트의 카테고리를 따라 자동으로 만들어집니다.

**Q. 관리자 주소(/admin)가 공개되는데 괜찮나요?**
주소는 공개되어도, **본인의 GitHub 토큰(해당 저장소 쓰기 권한)** 없이는 아무도 로그인하거나 내용을 바꿀 수 없습니다. 토큰만 유출하지 않으면 됩니다.

**Q. 이미지가 안 보여요.**
이미지는 `images/uploads/` 에 저장되고 경로는 `/images/uploads/파일명` 으로 기록됩니다. 사이트를 도메인 루트에 배포했다면 정상 동작합니다.

**Q. 여러 명이 함께 관리하고 싶어요.**
각자 자신의 GitHub 토큰으로 로그인하면 됩니다. 사람이 많아지면 토큰 대신 OAuth 로그인(별도 설정)을 붙일 수도 있으니, 필요할 때 문의하세요.
